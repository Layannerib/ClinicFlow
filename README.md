# ClinicFlow

## Sistema de Gerenciamento de Filas e Atendimento Odontológico

### 1. Sobre o projeto
O ClinicFlow é um sistema desenvolvido para organizar o fluxo de pacientes de uma clínica odontológica, desde o registro de sua chegada até a finalização do atendimento.

O sistema tem como objetivo facilitar o gerenciamento das filas de espera, a geração de senhas e o registro dos atendimentos realizados.

### 2. Objetivo

Desenvolver um sistema de gerenciamento de filas e atendimentos para facilitar o fluxo dos atendimentos e diminuir o tempo de espera dos clientes

### 3. Funcionalidades

- Cadastro de pacientes.
- Cadastro de funcionários.
- Geração de senhas.
- Gerenciamento de fila normal e prioritária.
- Chamada do próximo paciente.
- Registro de início e finalização do atendimento.
- Consulta ao histórico de atendimentos.

### 4. Tecnologias utilizadas

- MySQL 8 – Banco de dados.
- MySQL Workbench – Modelagem e administração.
- Python – Linguagem do backend.
- FastAPI – Framework para criação da API.
- Git e GitHub – Versionamento do projeto.
